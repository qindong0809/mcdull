# 本地启动说明

本文适用于 `revision 1.0.0`。业务服务统一使用 `local` / `test` / `prod` profile，`SPRING_PROFILES_ACTIVE` 必填（fail-fast）。环境配置统一在 `*-bootstrap`，`impl` 模块不再存放环境配置。

> 核心用法：复制第 1 节中对应服务的整行环境变量，粘贴到 IDE 的 `Environment variables`，然后启动对应启动类即可。
>
> 示例中的 `NACOS_PWD=123456` 按你提供的基线保留；若本机 Nacos 仍是默认的 `nacos/nacos`，把该值改回 `nacos`。

---

## 1. 一键复制环境变量（重点）

### 1.1 公共基线

所有业务服务都以此开头：

```text
SPRING_PROFILES_ACTIVE=local;NACOS_ADDR=mcdull.io:8848;NACOS_USER=nacos;NACOS_PWD=123456
```
