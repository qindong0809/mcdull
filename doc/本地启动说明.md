# 本地启动说明

本文适用于 `revision 1.0.0`。业务服务统一使用 `local` / `test` / `prod` profile，`SPRING_PROFILES_ACTIVE` 必填（fail-fast）。环境配置统一在 `*-bootstrap`，`impl` 模块不再存放环境配置。

> 核心用法：复制第 1 节中对应服务的整行环境变量，粘贴到 IDE 的 `Environment variables`，然后启动对应启动类即可。
>
> 示例中的 `NACOS_PWD=123456` 按你提供的基线保留；若本机 Nacos 仍是默认的 `nacos/nacos`，把该值改回 `nacos`。

### 1.8 PowerShell 批量注入

如果不用 IDE，而是用 PowerShell 启动，可把上面任意一行整行复制给下面的 `$block`，一次注入全部变量：

```powershell
$block = @'
SPRING_PROFILES_ACTIVE=local;NACOS_ADDR=mcdull.io:8848;NACOS_USER=nacos;NACOS_PWD=123456;SYSTEM_SERVER_PORT=8099;SYSTEM_DB_URL=jdbc:mysql://mcdull.io:3306/mcdull-cloud-3?useUnicode=true&characterEncoding=utf8&allowMultiQueries=true&serverTimezone=Asia/Shanghai;SYSTEM_DB_USER=root;SYSTEM_DB_PASSWORD=123456;SYSTEM_REDIS_HOST=mcdull.io;SYSTEM_REDIS_PORT=6379;SYSTEM_REDIS_DB=1;SYSTEM_REDIS_PASSWORD=;SYSTEM_DRUID_ADMIN_USER=root;SYSTEM_DRUID_ADMIN_PASSWORD=;SYSTEM_LOG_PATH=./logs
'@

$block -split ';' | Where-Object { $_ -match '^([^=]+)=(.*)$' } | ForEach-Object {
    [Environment]::SetEnvironmentVariable($Matches[1], $Matches[2], 'Process')
}
```

macOS / Linux 使用 `export KEY=value`，不要把分号整行直接粘到 shell。

## 2. 启动类与启动命令


IDE 启动：

1. 打开 `Run/Debug Configurations`，新增 `Spring Boot`。
2. `Main class` 选择上表对应启动类。
3. 把第 1 节对应服务的整行粘贴到 `Environment variables`。
4. 不要只在 `Active profiles` 填 `local`；配置里的 `${SPRING_PROFILES_ACTIVE}` 需要环境变量解析。

命令行启动（以 system 为例）：

```powershell
Set-Location 'd:/workspace/code/mcdull'
mvn -pl mcdull-business/mcdull-business-system/system-bootstrap spring-boot:run
```

首次构建：

```bash
mvn clean install -DskipTests
```

建议启动顺序：

```text
Nacos → MySQL/Redis → monitor（可选） → system → gateway → workflow / blaze / focus / demo
```

> `blaze`、`workflow` 的 Feign/SPI 调用依赖 `system` 服务在线。

## 3. 数据库与库名

按顺序执行 `sql/` 下的基础脚本：


按需执行：

| 脚本 | 对应服务 | 默认库 |

| `sql/demo.sql` 或 `mcdull-business/mcdull-business-demo/sql/demo.sql` | demo | `demo` |

如库名或账号不同，替换第 1 节对应行中的 `<PREFIX>DB_URL` / `<PREFIX>DB_USER` / `<PREFIX>DB_PASSWORD`。

## 4. Nacos 准备

### 4.1 基本检查

- 第 1 节示例使用 `NACOS_ADDR=mcdull.io:8848`；若 Nacos 在本机，把地址改成 `localhost:8848`。
- 业务服务与网关默认使用 Nacos `public` 命名空间；需要使用独立命名空间时追加 `NACOS_NAMESPACE=local`。
- 环境变量优先级高于 Nacos 共享配置和 jar 内 yml。

### 4.2 共享 Data ID

可先导入仓库基线配置：

```text
doc/nacos_config_export_20240421173102.zip
```

并确认 `DEFAULT_GROUP` 下存在：

| Data ID | 用途 |
|---|---|
| `datasource.yaml` | 数据源公共配置 |
| `redis.yaml` | Redis 公共配置 |
| `sa-token.yaml` | Sa-Token 公共配置 |
| `log-level.properties` | 日志级别公共配置 |
| `springboot-admin.yaml` | Spring Boot Admin 公共配置 |

服务私有配置按需准备：

```text
system-bootstrap-local.yaml
blaze-bootstrap-local.yaml
focus-bootstrap-local.yaml
workflow-bootstrap-local.yaml
demo-bootstrap-local.yaml
mcdull-gateway-local.yaml
```

共享配置导入使用 `optional:nacos:`：缺少 Data ID 不会阻断启动，但对应配置不会生效；Nacos 地址不可达时服务无法正常注册。

## 5. 环境变量速查

### 5.1 公共变量

| 变量 | 必填 | 示例值 | 说明 |
|---|---|---|---|
| `SPRING_PROFILES_ACTIVE` | 是 | `local` | 业务服务设为 `local`，网关设为 `dev` |
| `NACOS_ADDR` | 否 | `mcdull.io:8848` | Nacos 地址 |
| `NACOS_USER` | 否 | `nacos` | Nacos 账号 |
| `NACOS_PWD` | 否 | `123456` | 示例值；按实际 Nacos 密码调整 |
| `NACOS_NAMESPACE` | 否 | 空 | 默认 `public` 命名空间 |
| `ENV_TAG` | 否 | 空 | 灰度标签，单人不联调可留空 |
| `SPRING_BOOT_ADMIN_URL` | 否 | `http://localhost:9000` | 网关 `prod` 必填 |

### 5.2 服务前缀

| 服务 | 前缀 | 默认端口 |
|---|---|---:|
| system | `SYSTEM_` | 8099 |
| blaze | `BLAZE_` | 8090 |
| focus | `FOCUS_` | 6060 |
| workflow | `WORKFLOW_` | 6080 |
| demo | `DEMO_` | 6070 |
| gateway | `GATEWAY_` | 9090 |

> 网关只使用 `<PREFIX>SERVER_PORT`、`<PREFIX>LOG_PATH`、`<PREFIX>TAG_ENABLED`；DB/Redis 变量由 Nacos 的 `redis.yaml` / `datasource.yaml` 提供。

以 `<PREFIX>` 表示上表前缀：

| 变量 | 说明 | local 默认值 |
|---|---|---|
| `<PREFIX>SERVER_PORT` | 服务端口 | 各服务默认端口 |
| `<PREFIX>DB_URL` | JDBC 地址 | `jdbc:mysql://localhost:3306/<库名>?...` |
| `<PREFIX>DB_USER` | 数据库账号 | `root` |
| `<PREFIX>DB_PASSWORD` | 数据库密码 | `123456` |
| `<PREFIX>REDIS_HOST` | Redis 地址 | `localhost` |
| `<PREFIX>REDIS_PORT` | Redis 端口 | `6379` |
| `<PREFIX>REDIS_PASSWORD` | Redis 密码 | 空（空值表示不发送 AUTH） |
| `<PREFIX>REDIS_DB` | Redis 库索引 | `0`（system 为 `1`） |
| `<PREFIX>REDIS_TIMEOUT` | Redis 超时 | `3s`（system 为 `10s`） |
| `<PREFIX>TAG_ENABLED` | 标签路由开关 | `false` |
| `<PREFIX>LOG_PATH` | 日志根目录 | `./logs` |

部分服务专有变量：

| 变量 | 服务 | 说明 |
|---|---|---|
| `<PREFIX>DRUID_ADMIN_USER` / `<PREFIX>DRUID_ADMIN_PASSWORD` | 所有业务服务 | Druid 监控账号密码，默认 `root` / 空 |
| `SYSTEM_FILE_DOMAIN` / `SYSTEM_FILE_STORAGE_PATH` | system | 文件上传域名与存储路径 |
| `BLAZE_FILE_DOMAIN` / `BLAZE_FILE_STORAGE_PATH` | blaze | 同上 |

## 7. 常见问题

### 7.1 `Could not resolve placeholder 'SPRING_PROFILES_ACTIVE'`

业务服务未注入 `SPRING_PROFILES_ACTIVE`。请把第 1 节对应服务的整行环境变量粘贴到 IDE 的 `Environment variables`。

### 7.2 Nacos 连接失败

- 检查 `NACOS_ADDR` 是否可达；本机 Nacos 改为 `localhost:8848`。
- 检查 `NACOS_USER` / `NACOS_PWD` 是否正确。
- 检查 `NACOS_NAMESPACE` 对应命名空间是否已创建；未设置时默认使用 `local`。

### 7.3 数据库连接失败

- 检查 `<PREFIX>DB_URL` 中的库名是否存在。
- 检查 `<PREFIX>DB_USER` / `<PREFIX>DB_PASSWORD` 是否正确。
- MySQL 时区建议保留 `serverTimezone=Asia/Shanghai`。

### 7.4 端口被占用

修改对应服务的 `<PREFIX>SERVER_PORT`，例如把 `FOCUS_SERVER_PORT=6060` 改成 `FOCUS_SERVER_PORT=6061`。

### 7.5 共享配置未生效

检查 Nacos `DEFAULT_GROUP`（默认 `public` 命名空间）下是否存在 `datasource.yaml`、`redis.yaml`、`sa-token.yaml`、`log-level.properties`、`springboot-admin.yaml`。这些导入是 `optional`，缺失时不会报错，但配置不会加载。环境变量始终优先。

### 7.6 system/blaze 报 IP 库相关错误

这两个服务注册了 `Ip2RegionListener`，依赖 `logging.file.path`。当前配置已提供 `<PREFIX>LOG_PATH` 默认值 `./logs`；若目录无法创建，会自动降级到 JVM 临时目录，并且 IP 解析失败只会打印告警，不再阻断服务启动。建议本地把 `<PREFIX>LOG_PATH` 设置为明确的可写目录，例如 `D:/workspace/code/mcdull/logs`。
