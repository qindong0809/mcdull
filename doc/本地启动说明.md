# 本地启动说明

本文适用于 `revision 1.0.0`。业务服务统一使用 `local` / `test` / `prod` profile，`SPRING_PROFILES_ACTIVE` 必填（fail-fast）。环境配置统一在 `*-bootstrap`，`impl` 模块不再存放环境配置。

> 核心用法：复制第 1 节中对应服务的整行环境变量，粘贴到 IDE 的 `Environment variables`，然后启动对应启动类即可。
>
> 示例中的 `NACOS_PWD=123456` 按你提供的基线保留；若本机 Nacos 仍是默认的 `nacos/nacos`，把该值改回 `nacos`。
>
> 首次启动前请先在仓库根目录执行 `mvn clean install`（需要本机已安装 Maven 3.9.x，并配好全局 `settings.xml` 的内网 nexus 镜像）。该命令默认会跑单元测试与各模块的 ArchUnit 架构检查，请勿加 `-DskipTests`（仅本地紧急排查可临时使用，提交前须复验）。

---

## 1. 一键复制环境变量（重点）

三套 profile（`local` / `test` / `prod`）的**键集合完全一致**，只需替换 `SPRING_PROFILES_ACTIVE` 和对应环境的值。每个服务 10 项：公共 4 项 + 服务前缀 6 项。

已省略三套均有相同默认值的变量，无需再写：`*_REDIS_PORT`（6379）、`*_REDIS_DB`（1）、`*_REDIS_PASSWORD`（空）、`*_REDIS_TIMEOUT`（system 10s / 其他 3s）、`*_DRUID_ADMIN_USER`（root）、`*_DRUID_ADMIN_PASSWORD`（空）。

`*_DB_HOST` 只写主机名，端口 3306、库名和连接参数已在各服务 yml 中写死，不再提供完整 JDBC URL。

### 1.1 公共基线

所有业务服务都以此开头（4 项）：

```text
SPRING_PROFILES_ACTIVE=local;NACOS_ADDR=mcdull.io:8848;NACOS_USER=nacos;NACOS_PWD=123456
```

### 1.2 system-bootstrap（8099）

```text
SPRING_PROFILES_ACTIVE=local;NACOS_ADDR=mcdull.io:8848;NACOS_USER=nacos;NACOS_PWD=123456;SYSTEM_SERVER_PORT=8099;SYSTEM_DB_HOST=mcdull.io;SYSTEM_DB_USER=root;SYSTEM_DB_PASSWORD=123456;SYSTEM_REDIS_HOST=mcdull.io;SYSTEM_LOG_PATH=./logs
```
